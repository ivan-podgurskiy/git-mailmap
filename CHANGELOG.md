# Changelog

## 1.1.0 - 2026-08-18

- Require Node.js 20 or newer; Node.js 18 is no longer supported.
- Ship readable ESM and CommonJS bundles instead of minified output.
- Improve package README discoverability and remove a link to a file excluded from the npm tarball.

## 1.0.0 - 2026-08-16

- Add `.mailmap` parsing, identity resolution, and serialization.
- Ship ESM, CommonJS, and TypeScript declarations with no runtime dependencies.
- Build and verify release artifacts automatically before packaging.
- Document entry formats, project roadmap, and compatibility-test provenance.
